Decision Intelligence Report System

Stage 1. This is the reusable design language for every Validisory validation report. A report is generated from structured data, rendered on A4 master pages, and read in this order: decision, reasons, evidence, analysis, sources. The sample report applies the system to Micro-Tutorials AI (Report 17c91932).

A

Visual direction

The report should read like an investment committee memo set in the Validisory identity. Deep brand blue on white carries authority, and lavender marks what the system knows or recommends. The three secondary brand colours (teal, gold, copper) each name an analytical family. Each one also carries meaning: teal for support, gold for conditions, copper for exposure. No other colours are introduced. Every visual state also has a glyph, a position or a label, so the report still works in greyscale print.

H

Typography

Space Grotesk (primary, brand) for display, headings, labels and numbers. Montserrat (secondary, brand) for reading text. Sizes in px at A4 96 dpi; pt in brackets.

{{ t.role }} {{ t.sample }} {{ t.spec }}
Measure: body text max 68 characters (about 420px at 14px). Long analysis uses a 2-column 7/5 split with the margin column for metrics and source notes. Numbers always use tabular figures, and units are set at 0.6× the metric size.
GRID

Grid & spacing

HEADER · 28px
FOOTER · 24px

Page: A4, 210 × 297 mm, rendered as 794 × 1123 px. Margins 48 px left/right, 36 px top, 28 px bottom. All content is kept inside 794 × 1040 px so a page also prints on US Letter without clipping.

Columns: 12 columns, 16 px gutters, 698 px live width. Common spans are 12, 8+4, 7+5, 6+6, 4+4+4 and 3×4.

Page-edge tab: 5 × 120 px in the family colour on the right edge. Its vertical position is set by section number, so the edge of a printed stack works as a thumb index.

Spacing scale is on a 4 px base. Components use 8/12/16 internally. Blocks within a page are separated by 24/32. A new section on a page gets 48.
